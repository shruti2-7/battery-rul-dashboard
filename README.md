# Battery Health & RUL Dashboard

A data analytics mini project that monitors lithium-ion battery health and estimates remaining useful life (RUL) using NASA PCoE battery data.

- **Course:** 1BET307 Data Analytics (Module 1)
- **Data:** NASA PCoE battery cells B0005 to B0018 (`.mat` files)
- **Stack:** Python (preprocessing), HTML, CSS, JavaScript, Chart.js (dashboard)

## Project structure

```
battery-rul-dashboard/
├── data/                  # NASA .mat files (not committed, see .gitignore)
├── docs/                  # Dashboard served by GitHub Pages
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   └── data/batteries.json   # generated by preprocess.py
├── preprocess.py          # cleansing, transformation, modelling
├── requirements.txt
└── README.md
```

## Analytics workflow

1. **Question:** Can we predict when each cell will reach end of life?
2. **Collection:** Load NASA `.mat` discharge data.
3. **Cleansing:** Keep discharge cycles only and check for invalid values.
4. **Transformation:** Compute capacity and State of Health (SOH) per cycle.
5. **Modelling:** Fit a linear degradation trend on recent cycles and extrapolate to the 70% EOL threshold.
6. **Visualization:** Dashboard charts in `docs/`.
7. **Insight & decision:** Summaries of remaining life and replacement timing.

## Run locally

```bash
conda activate battery
pip install -r requirements.txt
python preprocess.py          # writes docs/data/batteries.json
cd docs && python -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Publish on GitHub Pages

1. Create a new repository on GitHub and push this folder.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/docs` folder, then save.
4. Your dashboard will be live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- RUL is a simple linear estimate, so it is a baseline model and not a final prediction.
- EOL is defined as 70% of the rated 2 Ah capacity (1.4 Ah).
